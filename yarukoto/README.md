# やることボード（小学1年生むけ）

iPad の Safari で `index.html` を開き、「共有 → ホーム画面に追加」で使います。データは iPad の中（localStorage）に保存されます。

- ☀️ きょう：あさ・よるのルーティン／きょう／こんしゅう。🔴やること・🟡やるといいこと・🔵やりたいこと を色で区別。⭐で「きょうのいちばん」を1つ選ぶ。🔴は1日3つまで。
- 🌸 カレンダー：ルーティンと🔴が全部できた日はハナマル、少しできた日は◯（×はつけない）。こんしゅうのふりかえり付き。
- 🪜 もくひょう：長い目標をかいだんで見える化。
- 🖨️ いんさつ：月のカレンダー・ルーティン表・目標のかいだんを A4 で印刷。

独立した1ファイルなので、別リポジトリへそのまま移せます。
