# がんばりスケジュール 🦎

小学2年生向けの学習管理Webアプリです。白×グレーを基調としたシンプルなデザインで、黒いヤモリのキャラクター「ヤモちゃん」といっしょに、毎日の課題を楽しくクリアしていきます。

## つかいかた

`index.html` をブラウザで開くだけで動きます。サーバーもインストールも不要です。

- **タブレット対応**: iPad などのタブレットのブラウザでそのまま使えます（大きなタッチボタン設計）
- **データ保存**: 端末のブラウザ（localStorage）に自動保存されます

GitHub Pages などで公開すれば、URLを開くだけでどの端末からも使えます。

## きのう

| きのう | せつめい |
|---|---|
| 📅 日にちごとの管理 | 週カレンダーで日付を選んで、その日の課題を表示 |
| 🕐 時間ごとの管理 | 課題に開始時刻を設定でき、時間順に並びます（時間なしもOK） |
| ➕ 課題の追加 | よく使う課題はワンタップで選択。自由入力もできます |
| ⭐ 達成感のしかけ | 「できた！」で星ゲット＋紙吹雪。1日全部クリアで大きなお祝い画面 |
| 🥚 たまごえらび | はじめて開いたとき、5種類のたまごから好きなものを選んでスタート（選択時に確認あり） |
| 🦎 キャラクター育成 | 星を集めるとたまごがかえり、生きものが成長します（たまご → うまれたて → こども → おとな → ママの5段階）。5種類の生きものを用意 |
| ✨ レベルアップ演出 | 一段階成長した瞬間、成長した姿を大きく表示してお祝いします |
| 🔁 課題の候補登録 | 一度つくった課題は次回から候補チップとして表示（新しく登録したものほど上に表示）。✕ボタンで候補から削除もできます |
| 🥚 あたらしい たまごへ | 最後まで育てると「あたらしい たまごを えらぶ」ボタンが出現。星が0に戻り、別の生きものを育て直せます |
| 📖 そだてた ずかん | 最後まで育てた生きものは、孵化から大人までの全段階の画像を図鑑で見返せます |
| ✏️ へんしゅうモード | 課題の削除は編集モードからのみ（誤操作防止） |
| ⏰ タイマー | ヘッダーの⏰ボタンから、扇形が減っていくビジュアルタイマー（残り時間の数字つき）。60・45・30・15・5・1分から選べ、終わると紙吹雪＋音でお知らせ |
| 🔄 さいしょから やりなおす | へんしゅうモード中に表示される小さなボタンから、全データ（課題・星・育成記録）を消して最初の状態に戻せます（2段階の確認あり）。新しい端末で開いた場合は、この操作をしなくても最初から自動的にまっさらな状態です |

## 小学2年生への配慮

- 文字はすべて **ひらがな中心** の表示
- ボタンは大きく、タップでの操作のみで完結
- 間違えて「できた」にしても、もう一度タップで戻せます

## いまの たまご と 生きもの

| たまご | 生まれる生きもの |
|---|---|
| 🥚 しろたまご | クロヤモリ（黒白のヤモリ） |
| 🥚 さくらたまご | タンジェリンレオパ（オレンジのヒョウモントカゲモドキ） |
| 🥚 そらたまご | アオウミガメ（青いウミガメ） |
| 🥚 わかばたまご | ミドリヘビ（緑のヘビ） |
| 🥚 ほしたまご | ハイイエローレオパ（黄色のヒョウモントカゲモドキ） |

各生きものは4段階（うまれたて → こども → おとな → ママ）で成長します。
生きものの画像は `index.html` 内の `SPECIES_IMG` にWebP形式で埋め込み済みです。
元画像は `assets/original/` にあります。

## 開発者向け：たまご・生きものの増やしかた

設定はすべて `index.html` 内の2つの設定オブジェクトにまとまっています。

### たまごを増やす（`EGGS` 配列に1行追加）

```js
const EGGS = [
  { id: "shiro", name: "しろたまご", base: "#f2ede3", deco: "spots", decoColor: "#d5cbba", species: "yamori" },
  // ↓ たとえばこう追加
  { id: "yuuhi", name: "ゆうひたまご", base: "#f7e3d0", deco: "stripes", decoColor: "#e0a878", species: "tangerine" },
];
```

- `id` — 重複しない英数字のID（保存データに使われます）
- `name` — 画面に表示される名前
- `base` — たまごの地の色
- `deco` — 模様の種類：`spots` / `stripes` / `zigzag` / `hearts` / `stars` / `none`
- `decoColor` — 模様の色
- `species` — このたまごから生まれる生きもの（下の `SPECIES` のキー）

### 生まれる生きものを増やす（`SPECIES` にエントリ追加）

```js
const SPECIES = {
  yamori: { ... },
  // ↓ たとえばこう追加
  tokage: {
    name: "ミドリトカゲ",      // ずかん上の名前
    nick: "トカちゃん",        // セリフで使われる呼び名（「{nick}も うれしいよ〜！」など）
    stages: [                  // 成長段階（数はいくつでもOK）
      { need: 3,  name: "うまれたてトカ", img: "assets/tokage-1.png" },
      { need: 10, name: "あかちゃんトカ", img: "assets/tokage-2.png" },
      { need: 25, name: "おとなトカ",     img: "assets/tokage-3.png" },
    ],
  },
};
```

- `need` — その段階になるのに必要な星の数（昇順で書く）
- `img` — 画像。`assets/xxx.png` のようなファイルパスでも、data URI（埋め込み）でもOK
- 追加した生きものは、`EGGS` のどれかの `species` に指定すると、そのたまごから生まれます

## ぎじゅつ

HTML / CSS / JavaScript のみ（依存ライブラリなし）。

- `index.html` — アプリ本体（キャラクター画像はWebP形式でファイル内に埋め込み済み。このファイル1つだけで動きます）
- `assets/original/` — キャラクターの元画像（高解像度）
